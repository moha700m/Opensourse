# Contributing to OpenShorts

Thanks for helping make long-form video easier to reuse.

## Before you start

- Open an issue for larger changes so we can agree on the direction.
- Keep API keys, downloaded videos, transcripts, and rendered clips out of commits.
- Prefer focused pull requests with a short explanation of the user-facing change.

## Local setup

Follow the setup steps in [README.md](README.md). FFmpeg must be available on your path. Whisper downloads its model the first time it runs.

## Pull requests

Describe what changed and how you checked it. Include screenshots for interface changes when useful. Keep existing formats and local-first behavior unless a change explicitly requires otherwise.
