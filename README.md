# OpenShorts

**حوّل الفيديو الطويل إلى شورتات جاهزة للنشر.** اختر فيديو من استديو الجوال أو الملفات ليبدأ رفعه وتحويله تلقائيًا، أو استخدم رابط YouTube.

OpenShorts يعمل محليًا على جهازك. يستخدم Faster-Whisper لتفريغ الكلام، وOpenRouter لتحليل النص وترشيح اللحظات. يمكنك أيضًا تشغيل اختيار احتياطي محلي بالكلمات المفتاحية من دون مفتاح API.

## المزايا

- تحليل الفيديو كاملًا واقتراح لحظات ذات بداية واضحة وفكرة مكتملة.
- قصّ الفيديو إلى صيغة عمودية 9:16 مناسبة لـ YouTube Shorts وTikTok وInstagram Reels.
- إنشاء ترجمة تلقائية وحرقها داخل الفيديو، مع ملفات SRT منفصلة.
- اختيار عدد المقاطع وطولها.
- رفع ملفات MP4 وMOV من الجوال تلقائيًا، مع نقلها على أجزاء واستكمال الرفع عند انقطاع الشبكة. اختر نفس الملف بعد تحديث الصفحة للاستكمال.
- رفع ملف YouTube cookies اختياري إذا منع YouTube التنزيل من الخادم.
- واجهة عربية باتجاه RTL، وتشغيل محلي يحفظ الملفات على جهازك.
- OpenRouter اختياري: أدخل مفتاحك من الواجهة، أو عيّنه في متغير البيئة.

## المتطلبات

- Python 3.10 أو أحدث.
- FFmpeg مع مرشّح `subtitles` وخط يدعم العربية. Dockerfile يضمّن FFmpeg وخط Noto.
- اتصال بالإنترنت لجلب فيديو YouTube، واتصال أول مرة لتنزيل نموذج Whisper المحلي.
- مفتاح OpenRouter لتحليل اللحظات بالنموذج. بدونه يعمل الاختيار المحلي الاحتياطي.

## التشغيل محليًا

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env      # اختياري
uvicorn main:app --reload
```

افتح [http://localhost:8000](http://localhost:8000). يمكنك إدخال مفتاح OpenRouter من لوحة الإعدادات؛ لا يُحفظ المفتاح في المتصفح أو على القرص، ويظل في ذاكرة عملية الخادم. أو أضفه إلى `.env` كـ `OPENROUTER_API_KEY`.

إعدادات اختيارية:

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `OPENROUTER_API_KEY` | فارغ | مفتاح OpenRouter. لا ترفعه إلى GitHub. |
| `OPENROUTER_MODEL` | `openai/gpt-4o-mini` | معرّف نموذج مدعوم على OpenRouter. |
| `WHISPER_MODEL` | `base` | نموذج Faster-Whisper المحلي؛ مثل `small` لتحسين الدقة على حساب السرعة. |
| `OUTPUT_DIR` | `./output` | مكان حفظ الفيديوهات والملفات. |
| `MAX_UPLOAD_SECONDS` | `14400` | الحد الأعلى لطول الفيديو بالثواني (4 ساعات). |
| `MAX_UPLOAD_BYTES` | `1073741824` | الحد الأعلى لحجم الفيديو المرفوع (1 غيغابايت). |
| `WHISPER_CACHE_DIR` | افتراضي المكتبة | مجلد نموذج التفريغ؛ صورة Docker تجهّز نموذج `tiny` أثناء البناء. |
| `APP_USERNAME` / `APP_PASSWORD` | `openshorts` / فارغ | حماية دخول Basic Auth عند إتاحة الخدمة عبر الإنترنت. |

عند النشر العام، عيّن `APP_PASSWORD` قبل التشغيل. سيطلب المتصفح بيانات الدخول قبل فتح الواجهة أو واجهات API. مسار `/healthz` متاح لفحص صحة الخدمة. التشغيل المحلي يبقى بلا حماية ما لم تضبط كلمة المرور.

## التشغيل عبر Docker

```bash
docker compose up --build
```

افتح [http://localhost:8000](http://localhost:8000). الملفات الناتجة تبقى في مجلد `output`.

## طريقة العمل

1. يستقبل الفيديو من الجوال على أجزاء بحجم 8 ميغابايت أو يجلب الرابط عبر `yt-dlp`.
2. يفرّغ المسار الصوتي باستخدام Faster-Whisper على دفعات من خمس دقائق، مع الحفاظ على توقيت الفيديو الأصلي لتقليل الذاكرة المستخدمة مع الفيديوهات الطويلة.
3. يرسل النص والتوقيتات فقط إلى النموذج عبر OpenRouter لاختيار اللحظات. لا يُرسل ملف الفيديو أو الصوت إلى OpenRouter.
4. يقصّ اللحظات المختارة ويعيد تأطيرها عموديًا من منتصف الصورة، ثم يحرق الترجمة باستخدام FFmpeg.

الرفع من الجوال يبدأ بمجرد اختيار الملف. أبقِ الصفحة مفتوحة حتى يكتمل الرفع؛ بعدها تجري المعالجة على الخادم. تُحذف ملفات المصدر والصوت الوسيطة بعد انتهاء المحاولة، وتبقى المقاطع والنتائج في `OUTPUT_DIR`. احفظ المقاطع المهمة على جهازك؛ التخزين في Render المجاني مؤقت، وقد تزول الملفات عند إعادة نشر الخدمة أو إيقافها.

عند رفض YouTube تنزيل الرابط بسبب طلب التحقق، استخدم ملف الفيديو من الجوال. لا يمكن للموقع استخدام تسجيل دخول تطبيق YouTube على هاتفك تلقائيًا.

إذا طلب YouTube تسجيل الدخول للتحقق من طلب التنزيل، يمكن رفع ملف `cookies.txt` من الواجهة. لا ترفع الملف إلا إلى نسخة OpenShorts التي تديرها وتثق بها؛ فهو يحتوي بيانات جلسة حسابك. يقتصر الملف الذي يستخدمه التطبيق على نطاقات YouTube وGoogle، ثم يُحذف بعد محاولة التنزيل. طريقة التصدير موضحة في [دليل yt-dlp الرسمي](https://github.com/yt-dlp/yt-dlp/wiki/Extractors#exporting-youtube-cookies).

لأفضل النتائج، استخدم فيديو تملك حق استخدامه أو لديك إذن بتنزيله وإعادة نشره. اختيار اللحظات آلي وقد يحتاج مراجعة قبل النشر. المعالجة تستخدم قصًّا مركزيًا ولا تتبع حركة المتحدث.
